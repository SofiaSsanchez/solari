# Solari · Tienda

- `productos.js`: tu número de WhatsApp, medios de pago/entrega y la lista de productos (precio `p`, stock `s`, `off:true` para ocultar).
- `img/`: una foto por producto, con el mismo nombre que su `id` (ej. `aro05.jpg`).
- `index.html`: la página. Normalmente no hace falta tocarla.

Para probar en tu compu: abrí `index.html` en el navegador (o usá la extensión Live Server de VS Code).
Para publicar: GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.
